** Monolitic :
   If hardware server have all fontend,backend,DB,info,payment,authentication
   Is called monolitic is good for small scale application.
   For large scale,if server side rendering:-
   -Entire app must be redeployed for small changes
   -Hard to scale individual features
   -One bug can affect the whole system
   -Performance bottlenecks under heavy load

** Microiltic :
   All fontend,backend.. kept in different hardware server & they are connected with each other through API.    
   You can use multiple tech-stack : react & angular can be used for different purpose. 
   ONLY IN Microiltic. Deployment is complex than monolitic.
   Easy scaling.
   * API : Talk with each other!
