** app.use("/", (req,res,next)=>{

     next();// goes to next callback Or method

** next() goes to the next matching handler in order of definition.
✅ The next callback of the same app.use()
✅ Another app.use("/")
✅ A route handler like app.get("/"), app.post("/"), etc.Prefix wise
app.use()   → runs first (method-agnostic)
next()      → continue
app.get()   → ONLY if request method === GET
app.patch() → ONLY if request method === PATCH

** Prefix matching : 
app.use("/admin") matches ALL paths that START with /admin
* So it matches:
/admin
/admin/1
/admin/abc
/admin/settings/profile
