** What is Semi-Structured Data?
Data that does not follow a strict table schema (rows & columns),
but still has some structure (keys, tags, hierarchy).
It sits between structured and unstructured data.
Eg : JSON, XML 

** SQL : ACID property 
Actomicity :Either all operations succeed Or none of them are applied
consistency:A transaction must take the database from one valid state to another.
isolation  :Multiple transactions run as if they were sequential.
durability :Once a transaction is committed, it stays — even after crash.
