** Server Express :-
    const express = require('express');
    const app = express();// server created

** Custom Port :-
    app.listen(400, ()=>{
        console.log("Port : 400");
    })

** Route :-
    * app.use() -> middle ware
    app.use("/route", (request,respond)=>{ // localhost:400/route
        res.send(
            {
                "Name":"Krish"
            }
        )
    })
    ** "/" should always be at last or else app.use("/",()=>{}) will alwasy be shown
    ** "/ho?me" -> o becomes optional -> localhost:400/hme || localhost:400/home
    ** "/hom+e" -> unlimited m -> localhost:400/hommme
    ** "/hom*t" -> hom write anything end with 't' -> localhost:400/homdhuwdiuwhiuwhiuwt
    
** Dynamic route : PARAMS 
 "/home/:id" -> request.params -> prints the id fromlink
